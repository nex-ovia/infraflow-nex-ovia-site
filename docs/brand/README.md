# nex-ovia mark: "horizon & path"

The oval is the O of nex-o-via, parted by a horizontal cut: the horizon. `nex` (next) is knocked out of the
solid half that rises above it. Below, `via` (by way of) sits in a bowl drawn as one calligraphic stroke: heavy
at the left, thinning as it climbs, then leaving the O and running out along the horizon to a single point, the
destination. That point is also the middle dot of nex·ovia. The brand in one line: the next generation, and the
path to it.

Letters are DM Serif Display (SIL OFL), the site's headline face, outlined so the files need no font.

- `brand/nex-ovia-mark.svg`: indigo `#6c63ff` / teal `#00d4aa`, dark backgrounds
- `brand/nex-ovia-mark-light.svg`: one-colour ink `#14131c`, light backgrounds and print
- `brand/nex-ovia-mark-white.svg`: one-colour, photos, video and brand colour
- `brand/nex-ovia-symbol*.svg`: letterless, favicons and anything under ~40px
- `brand/avatar-1080.png`, `linkedin-banner-1584x396.png`, `x-header-1500x500.png`, `youtube-banner-2560x1440.png`

Rebuild: `python mark.py DMSerifDisplay-Regular.ttf <out-dir>` (needs `fonttools`; font from
https://github.com/google/fonts/tree/main/ofl/dmserifdisplay).
