genome

Understand any system without reading its code.

beta · v0.1.0-alpha.1

genome turns one editable nexovia.toml into a self-contained, offline HTML map of your project: its architecture, every module, what each part does and why, so architects, engineers and executives can see it, question it and approve it in the browser.

  • Offline, read-only HTML map
  • Exec, architecture and engineering views
  • Prebuilt for Linux, macOS and Windows
  • Install: curl -fsSL https://genome.nex-ovia.com/install.sh | sh

coderev

One command to scan your code, map it, and get an AI review.

beta · v0.30.4

Deterministic static analysis and rules run first; a bounded AI review runs second, so the AI only sees what matters.

  • brew install srivastava-ami/tools/coderev
  • No Python, no Node, no config file
  • Rules first, AI second
